## fix: 拖拽松手后图片位置跳变（交换而非移动）

### 根因分析
拖拽松手时出现"图片 A 和 B 交换位置"而非"其它图片依次后移"的现象，完整链路如下：

1. 拖拽中 `previewOnItemMove` 做单步 `Collections.swap` + `notifyItemMoved`，本地顺序已正确
2. 松手 `clearView` → `getImages()` 收集最终顺序 → `ReorderImages` → ViewModel → 新 State emit
3. `render()` 里 `state.selectedImages !== lastImageList`（引用比较）为 true（两个不同 ArrayList 实例）
4. 触发 `updateData()` → `notifyDataSetChanged()` → RecyclerView 重新测量，打断 ItemTouchHelper 松手动画
5. 视觉上：ItemTouchHelper 还在播放回弹动画，RecyclerView 同时刷新，出现位置跳变/交换感

### 修复
**MainActivity.kt**：
- `clearView` 里提交 `ReorderImages` 前，先 `lastImageList = finalOrder`（提前同步缓存引用）
- 九宫格刷新判断从引用比较 `!==` 改为**内容比较** `!=`（Uri List 的 equals 是内容比较），确保内容相同时不触发 `notifyDataSetChanged`

```kotlin
// 改动1: clearView
val finalOrder = ArrayList(imageGridAdapter.getImages())
lastImageList = finalOrder  // ← 先同步，防止 render() 二次刷新
viewModel.sendIntent(PublishIntent.ReorderImages(finalOrder))

// 改动2: render()
if (state.selectedImages != lastImageList) {  // != 内容比较，而非 !== 引用比较
    imageGridAdapter.updateData(state.selectedImages)
    lastImageList = state.selectedImages
}
```
