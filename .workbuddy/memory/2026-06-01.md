## fix: 拖拽松手后图片位置跳变（交换而非移动）

### 根因分析
拖拽松手时出现"图片 A 和 B 交换位置"而非"其它图片依次后移"的现象，完整链路如下：

1. 拖拽中 `previewOnItemMove` 做单步 `Collections.swap` + `notifyItemMoved`，本地顺序已正确
2. 松手 `clearView` → `getImages()` 收集最终顺序 → `ReorderImages` → ViewModel → 新 State emit
3. `render()` 里 `state.selectedImages !== lastImageList`（引用比较）为 true（两个不同 ArrayList 实例）
4. 触发 `updateData()` → `notifyDataSetChanged()` → RecyclerView 重新测量，打断 ItemTouchHelper 松手动画
5. 视觉上：ItemTouchHelper 还在播放回弹动画，RecyclerView 同时刷新，出现位置跳变/交换感

### 修复
**MainActivity.kt**：
- `clearView` 里提交 `ReorderImages` 前，先 `lastImageList = finalOrder`（提前同步缓存引用）
- 九宫格刷新判断从引用比较 `!==` 改为**内容比较** `!=`（Uri List 的 equals 是内容比较），确保内容相同时不触发 `notifyDataSetChanged`

```kotlin
// 改动1: clearView
val finalOrder = ArrayList(imageGridAdapter.getImages())
lastImageList = finalOrder  // ← 先同步，防止 render() 二次刷新
viewModel.sendIntent(PublishIntent.ReorderImages(finalOrder))

// 改动2: render()
if (state.selectedImages != lastImageList) {  // != 内容比较，而非 !== 引用比较
    imageGridAdapter.updateData(state.selectedImages)
    lastImageList = state.selectedImages
}
```

## feat: 草稿自动保存（WTT JSON 格式 + 防抖 + 图片持久化 + onStop 强制落盘）

### 新增文件
- **DraftManager.kt** — 草稿管理器，负责 JSON 序列化/反序列化、图片复制到 app-private 存储

### 存储格式（参照微头条 WTT 草稿结构）
- JSON schema: `{ version, text, images[], formatSpans[], savedAt }`
- 图片复制到 `filesDir/draft_images/draft_img_*.jpg`（跨 session 持久化）
- SpanDescriptor 复用现有 `"start|end|type|value"` 格式

### PublishState 新增字段
- `hasDraft`, `showDraftPrompt`, `draftSavedAt`, `draftTextLength`, `draftImageCount`

### PublishIntent 新增意图
- `DraftDetected` — ViewModel init 检测到草稿后通知 View 层
- `RestoreDraft` — 用户选择恢复草稿
- `DismissDraft` — 用户放弃草稿
- `ForceSave` — Activity.onStop 时强制落盘

### PublishViewModel 核心逻辑
- `init {}` 检查草稿文件 → 有则设置 hasDraft/showDraftPrompt（跳过 SavedStateHandle 已有状态的情况）
- `scheduleAutoSave()`: 3s 防抖，TextChanged/ImagesPicked/RemoveImage/ReorderImages/SaveFormatting 后触发
- `handleRestoreDraft()`: 从 JSON 加载完整数据 → 更新 State → 删除草稿文件
- `handleDismissDraft()`: 删除草稿文件 + 清除弹框标记
- `handleForceSave()`: 取消防抖 → 立即保存当前状态
- 发布成功后自动删除草稿，DismissSuccess 重置表单后也删除

### MainActivity 改动
- `render()` 新增草稿弹框优先级（仅次于 publishSuccess）
- `showDraftRestoreDialog()`: Material AlertDialog，展示"X字，Y张图片\n上次保存：Z分钟前"
- `onStop()`: 发布成功页外强制保存（`viewModel.onActivityStop()`）

### strings.xml 新增
- `wtt_draft_found_title` = "发现草稿"
