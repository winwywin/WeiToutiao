## Day 17: 图片压缩 + 分步上传模拟 — commit fe5c869

### 新增/修改文件

**`model/PublishState.kt`**
- 新增 `uploadProgress: Int = 0`（0-100）
- 新增 `uploadStatusText: String = ""`

**`viewmodels/PublishViewModel.kt`**
- `ViewModel` → `AndroidViewModel`（需要 cacheDir）
- `handleClickPublish` 分三步：
  - Step1 压缩：IO 协程 `decodeSampledBitmap(1920px)` + `compressToFile(q85)`，进度 0→50%，文字 "正在压缩 x/n..."
  - Step2 上传：`delay(600ms/张)` 模拟上传，进度 50→100%，文字 "正在上传 x/n..."
  - Step3 清理：`cacheDir/compress/` 临时文件 + 重置 PublishState

**`res/layout/activity_main.xml`**
- Loading 遮罩：`ProgressBar`（旋转圈）→ `LinearLayout`（半透明卡片）
- 新增 `tv_upload_status`（步骤文字）、`pb_upload_progress`（水平进度条 0-100）、`tv_upload_percent`（百分比数字）

**`view/MainActivity.kt`**
- `render()` 中 `isLoading=true` 时更新三控件

### 关键决策
- `AndroidViewModel` 代替 `ViewModel + Application 注入`，避免复杂 Factory
- 压缩目标 1920px（发布分辨率），缩略图仍用 400px（九宫格），不互相干扰
- `delay(600ms/张)` 而非固定 `delay(2000)`，让进度条有真实感
- 无图片时跑一次假上传循环（避免 0 分母 + 保持 UX 一致）
