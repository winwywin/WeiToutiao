## fix: 相册图片不显示 — 三个根因修复

### 用户反馈
打开相册后选中框可见但图片全是空白（AsyncListDiffer + loadThumbnail 改动后）。

### 根因 1 — loadThumbnail 返回 null 不 fallback
`ContentResolver.loadThumbnail()` 在部分 ROM/格式下返回 null（不抛异常），原代码只有 try-catch，null 被直接 return，不会 fallback 到手动解码路径。

**修复**: 添加 `if (bitmap != null)` 检查，null 时 fall through 到手动解码。

### 根因 2 — FileDescriptor 未 seek
手动解码路径中，同一个 `pfd.fileDescriptor` 连续调用两次 `decodeFileDescriptor`（先 bounds 后实际 decode），第二次时文件指针在末尾 → 返回 null。这是经典 Android bug。

**修复**: 分两步各自 `openFileDescriptor`（bounds 用 pfd1，decode 用 pfd2），避免共用同一 fd 指针。

### 根因 3 — 布局 ImageView height=0dp
`item_gallery_photo.xml` 中 FrameLayout(wrap_content) 内的 ImageView 和 overlay 设了 `layout_height="0dp"` 且无 weight 约束 → 实际高度为 0 → 即使 bitmap 加载成功也看不见。

**修复**: 改为 `match_parent`。

### 编译
BUILD SUCCESSFUL，已 adb install 到设备。

## fix: previewOnItemMove 改为单步 swap（修复拖拽动画错乱）

### 根因
`previewOnItemMove` 用了多步循环 swap + 单次 `notifyItemMoved(from, to)`：
- ItemTouchHelper 是**逐位置**回调 `onMove`（每经过一格触发一次，from/to 相邻）
- 但多步 swap 后数据状态与 `notifyItemMoved(from, to)` 的参数不一致
- 例如 onMove(2,3): swap(2,3), swap(3,4), swap(4,5) + notifyItemMoved(2,5) → 数据错位

### 修复
改为 `Collections.swap(data, from, to)` + `notifyItemMoved(from, to)`，每次 onMove 只交换两个相邻位置，与 ItemTouchHelper 的增量回调完全对齐。

## fix: 主页九宫格图片模糊 — 三个修复

### 根因1 — loadThumbnail 可能返回极小缩略图
`ContentResolver.loadThumbnail(uri, Size(400,400))` 仅作大小**提示**，系统可能返回 MINI_KIND(512×384) 甚至 MICRO_KIND(96×96) 预缓存缩略图。在约 300+px 格子显示会被大幅放大 → 模糊。

**修复**: 添加尺寸守卫 — 若返回的 bitmap 宽/高任一 < target/2，则 `bitmap.recycle()` 后回退手动解码。

### 根因2 — 解码目标尺寸 400px 偏低
3x 密度屏每个格子约 303px 物理像素，400px 源图仅 1.3 倍余量，loadThumbnail 近似图稍小就不够清晰。

**修复**: `ImageGridAdapter.bindImageHolder()` 调用 `decodeSampledBitmap` 时传入 `targetWidth=800, targetHeight=800`。

### 根因3 — 缩略图缓存容量不足
800×800 RGBA 单张≈2.56MB，原 4MB 缓存仅能存 1-2 张 → 频繁 re-decode。

**修复**: `ThumbnailCache` 扩容至 16MB（可缓存约 6 张 800×800 缩略图）。
